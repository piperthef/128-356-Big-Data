## 📌 ภาพรวมรายวิชา
รายวิชานี้สำรวจแนวคิด หลักการ และเทคโนโลยีสำหรับการจัดการข้อมูลขนาดใหญ่ (Big Data) โดยเน้นสถาปัตยกรรมแบบกระจาย (distributed systems) ซึ่งเป็นรากฐานของ Data Engineering สมัยใหม่ ผู้เรียนจะได้เรียนรู้เกี่ยวกับการจัดเก็บข้อมูล (Storage), การประมวลผล (Processing), และการวิเคราะห์ (Analytics) บนข้อมูลที่มีปริมาณมหาศาล

> **Key Focus**: เปลี่ยนจากการใช้เครื่องมือสำเร็จรูป ไปสู่การเขียนโค้ดเพื่อควบคุมระบบ (Infrastructure as Code) และเข้าใจการทำงานเบื้องหลังของ Data Pipeline

## 📚 โครงสร้างรายวิชา (Syllabus)

### ส่วนที่ 1: ระบบไฟล์ฐานรากและรูปแบบข้อมูล (Files & Formats)
*   **สัปดาห์ที่ 1**: ภาพรวม Big Data และทำไมฐานข้อมูลเดิมจึงไม่เพียงพอ
*   **สัปดาห์ที่ 2**: Data Lake vs Data Warehouse และระบบไฟล์แบบกระจาย (HDFS, S3)
*   **สัปดาห์ที่ 3**: รูปแบบไฟล์เพื่อประสิทธิภาพ (Parquet vs CSV vs Avro) และการบีบอัด

### ส่วนที่ 2: การประมวลผลแบบกระจาย (Distributed Processing)
*   **สัปดาห์ที่ 4**: แนวคิด MapReduce และบทนำ Apache Spark
*   **สัปดาห์ที่ 5**: การแปลงข้อมูลด้วย Spark (Transformations & Actions)
*   **สัปดาห์ที่ 6**: การจัดการข้อมูลสูญหาย (Missing Data) และการทำความสะอาดข้อมูล

### ส่วนที่ 3: สตรีมมิงและการใช้งานจริง (Streaming & Application)
*   **สัปดาห์ที่ 7**: การประมวลผลข้อมูลสตรีมมิง (Streaming Analytics)
*   **สัปดาห์ที่ 8**: การวิเคราะห์ข้อมูลเบื้องต้น (EDA)
*   **สัปดาห์ที่ 9**: Machine Learning ในบริบท Big Data
*   **สัปดาห์ที่ 10**: การประกันคุณภาพข้อมูล (Data Quality Assurance)

### ส่วนที่ 4: จริยธรรมและโครงงาน (Ethics & Project)
*   **สัปดาห์ที่ 11**: จริยธรรมและความเป็นส่วนตัว (Data Ethics & Privacy)
*   **สัปดาห์ที่ 12**: ระบบควบคุมเวิร์กโฟลว์ (Airflow)
*   **สัปดาห์ที่ 13**: ประสิทธิภาพและต้นทุน (Performance & Cost)
*   **สัปดาห์ที่ 14-15**: โครงงานปลายภาคและการนำเสนอ

## 🛠️ เครื่องมือที่ใช้ (Tools & Tech Stack)
*   **Languages**: Python, SQL
*   **Storage**: Parquet, Arrow, DuckDB
*   **Processing**: Apache Spark (PySpark), Pandas
*   **Visualization**: Plotly, Streamlit
*   **Orchestration**: Apache Airflow
